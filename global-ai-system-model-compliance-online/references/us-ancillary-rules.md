# 美国附属法兼容入口

统一三层 Skill 的美国第三层已扩展为CCPA/CPRA、美国敏感数据跨境限制和相关联邦/州法筛查。完整规则、机器字段、官方来源和不确定性处理请读取 references/us-data-layer.md。

本文件只保留路由提示：

1. CCPA/CPRA、FTC Act、COPPA和已核验的DOJ Data Security Program属于按事实触发的强制性法律。
2. NIST、C2PA、行业框架、博客和白皮书属于建议性良好实践/解释性材料（非独立法定义务）。
3. EO 14117主要是联邦行政政策和规则授权来源；不要把它本身写成所有私营企业的普遍禁令。
4. 未核实的门槛、受关注国家、交易类型、豁免或未来日期必须标为待核，按最严格路径发出警示。
