# 未覆盖维度指针库

本统一 Skill 已覆盖三层：三地透明度、EU AI Act系统/模型、以及GDPR/CCPA/CPRA/跨境/美国敏感数据和PLD/CDSM/ePrivacy。以下事项不在默认结论内，报告只能提示“需另行专项评估”，不能临场编造条款：

1. 中国大陆非AI透明度的完整网络内容治理、数据出境审批、个人信息保护法全部制度和行业许可。
2. 欧盟DSA、DMA、NIS2、DORA、CRA、行业产品安全法规的完整独立合规（AI Act Annex I接口仍需评估）。
3. 欧盟成员国劳动法、医疗法、刑法、税法、消费者法和具体监管沙盒要求。
4. 美国除CCPA/CPRA、DOJ Data Security Program、FTC/COPPA及问卷点名法之外的州法和行业法的完整意见。
5. 生成内容的版权归属、商标/专利、商业秘密、合同争议和诉讼策略。
6. 金融、医疗、航空、汽车等行业的完整产品准入和安全认证。

若用户要求上述事项，先说明本 Skill 的覆盖边界，再列需要的主管机关、官方法规或外部律师核验。任何未覆盖或资料库缺口不得输出无条件“合规”。
