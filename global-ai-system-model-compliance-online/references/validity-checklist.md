# 法律效力和日期核验清单

本清单是交付前门禁。任何无法核验的项目都要标为pending_verification，并按最严格标准出风险提示。

## 一、来源层级

1. 欧盟条例和Official Journal最新合并文本。
2. 欧盟指令及目标成员国正式转置法。
3. 加州立法官网、CPPA最终规则、美国联邦法典和eCFR。
4. 中国大陆正式法规、部门规章和已生效强制标准。
5. Commission/AI Office指南、FAQ、CoP、标准化请求和标准：只作“欧盟建议的良好实践/解释性材料（非独立法定义务）”。
6. 提案、影响评估、新闻、律所文章和搜索摘要：只能作背景或线索，不能单独支撑强制结论。

## 二、三层法律核验

### Layer 1透明度

- 中国：核对《互联网信息服务深度合成管理规定》《生成式人工智能服务管理暂行办法》《人工智能生成合成内容标识办法》及适用技术标准的生效状态、对象、模态、公众传播和备案/评估条件。
- 欧盟：核对Regulation (EU) 2024/1689现行Art.50及已生效修订、适用日期和罚则；CoP/Art.50 Guidelines单列为建议实践。
- 加州：核对CAITA现行B&P Code §§22757及CPAA/立法官网；SB 1000等未生效文本集中放入未来变更提示。

### Layer 2系统和模型

- AI Act：核对Art.2/3、Art.5、Art.6、Annex I/III、Art.9-15、16-19、22-28、43、48-49、51-56、72-73、99、111、113及Omnibus。
- Annex I：联网脚本的清单必须恰好20项；产品法规以脚本下载的官方原文为准；历史Directive 2006/42/EC不得列作现行项目。
- GPAI：核对Art.3(63)-(68)、51-55、官方GPAI指南版本和系统性风险指定；指南中的计算量指标不能自动写成法定门槛。
- 日期：将已生效、未来适用、过渡和草案分列；引用日期时保留官方出处。

### Layer 3数据和相邻法

- GDPR：核对CELEX 32016R0679现行文本、EDPB官方决定/指南的状态；指南不得替代条例。
- 跨境：核对充分性决定、Art.46机制文本、SCC版本、BCR和Art.49条件；Schrems II/TIA作为评估记录，不是独立机制。
- PLD：核对Directive (EU) 2024/2853的成员国转置进度、产品定义和旧产品过渡。
- CDSM：核对Directive (EU) 2019/790及成员国转置、Art.3/4/7/17/28和权利保留。
- ePrivacy：核对Directive 2002/58/EC Art.5(3)及目标成员国转置；不要用指令原文代替本地执行法。
- CCPA/CPRA：核对California Civil Code和CPPA最终规则的当前门槛、SPI、sale/share、GPC和消费者请求时限。
- 美国敏感数据：核对EO 14117、28 C.F.R. Part 202 eCFR当前文本、受关注国家/实体、数据类别、数量阈值、交易类型、豁免和合规日期；不把行政命令政策目标写成一般私营企业禁令。

## 三、效力标签校验

每个法律来源必须填写：名称、法域、层级、来源类型、法律状态、是否有约束力、条号、版本、适用/生效日期、官方链接、本地路径、核验日期。

- binding_law、delegated_act、implementing_act：标签只能是“强制性法规”，binding=true。
- official_guidance、cop：标签只能是“欧盟建议的良好实践/解释性材料”，不得出现“强制”“安全港”“合规推定”。
- voluntary_standard：标签只能是“自愿性标准”。
- proposal：标签只能是“提案或草案”。
- secondary：标签只能是“二手资料”，不能单独支撑义务。

## 四、未知和矛盾门禁

1. 业务答“不确定”、留空或给出互相矛盾事实时，事实状态为unknown或conflicting。
2. 未知触发条件不得生成无条件applicable/compliant；改用conditional或block_until_verified。
3. 严格默认只用于触发风险和待办，不把未知能力、规模、角色或完成状态写成已经存在。
4. 对每个未知项记录责任部门、证据、完成标准和上线阻断条件。
5. 关键事实未核实时，综合结论不得是“合规”或“go”。

## 五、时间和复核

报告顶部记录知识截止日和法律核验日；高波动项目至少每90天复核一次，或在用户要求“按最新法规重新解读”、监管公告、重大版本/用途变化时立即复核。更新规则库使用：

python3 scripts/fetch_official_sources.py --profile all --dry-run

更新脚本不得删除旧原件；变化的文件保留日期化历史副本，并把链接失败、元数据缺口和待人工复核事项写入update-report.json。
