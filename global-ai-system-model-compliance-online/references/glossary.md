# 术语表

正文首次出现术语时用白话解释，括号保留英文。不要使用工程音译替代法律术语。

| 中文 | 英文 | 白话解释 |
|---|---|---|
| 人工智能系统 | AI system | 能根据输入推断并生成预测、内容、推荐或决定的机器系统 |
| 提供者 | provider | 开发或委托开发系统/模型，并以自己名称或商标投放或投入使用的一方 |
| 部署者 | deployer | 在自己权限下实际使用系统的一方 |
| 下游提供者 | downstream provider | 把模型集成进自己提供的AI系统的一方 |
| 通用人工智能模型 | general-purpose AI model, GPAI model | 能做多种不同任务、可集成到多种下游系统的模型 |
| 系统性风险 | systemic risk | GPAI高影响能力可能在欧盟市场大规模传播并造成重大影响的风险 |
| 不可接受风险 | unacceptable risk | AI Act禁止的用途或做法 |
| 高风险AI系统 | high-risk AI system | 进入Annex I安全组件路径或Annex III用途路径的系统 |
| 安全组件 | safety component | 故障会危及人身或财产安全，或用于预防/减轻此类风险的组件 |
| 预期用途 | intended purpose | provider在说明、营销或技术文档中设定的用途和条件 |
| 重大修改 | substantial modification | 投放后未预见的改变，影响合规或改变已评估用途 |
| 控制者 | controller | 决定个人数据处理目的和方式的一方 |
| 共同控制者 | joint controllers | 共同决定处理目的和方式的多方 |
| 处理者 | processor | 代表控制者处理个人数据的一方 |
| 分处理者 | sub-processor | 受处理者委托继续处理个人数据的一方 |
| 特殊类别个人数据 | special categories of personal data | GDPR Art.9列明的健康、种族、政治观点、生物识别等数据 |
| 数据保护影响评估 | DPIA | 评估高风险个人数据处理对个人权利影响的文件 |
| 标准合同条款 | SCC | GDPR Art.46保障措施的一种合同机制 |
| 传输影响评估 | TIA | 评估第三国法律、政府访问和补充措施的记录，不是独立法定机制 |
| 充分性决定 | adequacy decision | 欧盟认定某第三国保护水平足够的决定 |
| 敏感个人信息 | sensitive personal information, SPI | CCPA/CPRA列明的精确位置、健康、生物识别、账号凭证等类别 |
| 出售 | sale | CCPA下以金钱或其他有价值对价向第三方披露，范围不只现金 |
| 共享 | share | CCPA下为跨情境行为广告等目的披露，可能没有金钱对价 |
| 全球隐私控制 | Global Privacy Control, GPC | 浏览器或设备发送的统一退出出售/共享信号 |
| 文本和数据挖掘 | text and data mining, TDM | 自动分析数字文本、数据或模式的计算处理 |
| 检索增强生成 | retrieval-augmented generation, RAG | 先检索外部资料再生成回答的架构 |
| 终端设备 | terminal equipment | 用户设备及其存储/读取区域，如浏览器、手机和物联网设备 |
| 机器可读标记 | machine-readable marking | 软件可检测的元数据、水印或其他标记 |
| 深度伪造 | deep fake | 看起来像真实人物、物体、地点或事件但由AI生成/篡改的图像、音频或视频 |
| 产品缺陷 | defect | 产品不提供公众有权期待的安全程度，按PLD事实和法条判断 |
| 经济运营者 | economic operator | 制造商、进口商、分销商、授权代表等产品责任链主体 |
| 欧盟建议的良好实践/解释性材料 | EU recommended good practice/interpretive material | 指南、FAQ、CoP、标准等非独立法定义务材料 |
| 强制性法规 | binding law | 已生效、可约束相关主体的条例、指令转置法或正式决定 |
| 待核事实 | fact pending verification | 业务尚未能以证据确认的能力、规模、角色、数据流或实施状态 |
| 条件式义务 | conditional obligation | “若某事实成立，则应当履行某义务”的报告表达 |
| 上线阻断 | launch blocker | 在事实或义务闭环前不应上线的事项 |
